Moch Desktop — five directions. One wins.

Each mockup is a full static page of the whole app — open all five, look at them at full size, and tell me the winner (or "2 but with 4's statusbar", etc). Research behind them: research/desktop-ui-apps/ — six deep studies of DSH, Codex, Claude desktop, hermes desktop, opencode, ZCode.
1

Atelier

warm editorial · cream + coral · slab-serif · artifacts panel

The Claude-inspired direction: warm paper instead of dark, serif display type, and the killer pattern — an Artifacts side panel that opens beside the chat for self-contained output (live page preview, "Edit with Mochi" in place). Calm, literary, completely unlike any agent app on the market. Mochi's warmth, on the screen.

2

Ledger

typographic discipline · no boxes · live status row · sentence-scoped approvals

The Codex-inspired direction: hierarchy built from type alone — bullets, indents, fills, no cards. The signature is the live status row (the model's own reasoning as an animated headline + clock + esc-to-interrupt), tool rows with └ output tails and "+N lines" disclosure, "Worked for 5m 12s" turn separators, and an approval card whose options are full sentences. Dense, honest, keyboard-first. Keeps Moch orange as the single accent on near-black.

3

Deck

cards on deep canvas · session tabs · shimmering tool ledger · tri-region

The opencode-inspired direction: floating elevated cards on a near-black canvas, browser-style draggable session tabs in the titlebar, and the signature shimmering tool ledger — rows that glow while running and auto-group ("4 tools · 2 merged reads"). Permissions are a non-modal dock fused above the composer. Right side: file tree + diff card; far right: fleet strip + terminal card. Feels like a cockpit.

Open →03-deck.html
4

Mission

goal-loop ADE · workbench tabs · iteration checklists · tachometer statusbar

The ZCode-inspired direction: the app as a mission console. Titlebar carries live status chips (agents, needs-you, jobs, goal timer). The chat shows goal-loop iteration dividers and a checklist with amber "holes" waiting for a human. Right side is a tabbed workbench (Goal evidence / live Browser / Terminal / Diff) with a workflow mini-map of who's on what. Bottom is a full tachometer: turns · steps · tok/s · cache · context bar. Violet reasoning accents, black/white CTAs.

Open →04-mission.html
5

Bridge

bot-first command bridge · fleet rail · arc borders · status stack · Mocheme evolved

The hermes/opencode hybrid in Moch's own colors: the fleet is a left rail of bot squares with 7-state dots (working/needs-you/idle…), sessions beside it. Quiet scaffold-style tool rows that collapse into "4 tool calls · thought for a while" with a live ticker, a composer status stack (todos + livestreaming subagents fused above the input, arc-border ring while running), an inline ::preview live widget the agent rendered, and a [██████░░░░] context meter in the statusbar. The most "Moch" of the five.
