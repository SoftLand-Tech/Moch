Moch Sidebar — 10 Project-Scoped Concepts

In every layout, sessions live inside Projects: picking a project shows only its sessions.

Updated Rule Across All 10 Sidebars

Every concept below is now project-scoped: there is no global dump of unrelated sessions. Click any project (Moch App, Recipe Meal, Infra & Ops, or Personal) inside any mockup to see only that project's sessions live.

✓ Click a project → see only its sessions ✓ "+ New chat" lands in the chosen project ✓ Clean AI app conventions (no 8-section clutter)
