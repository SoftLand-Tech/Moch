# Site asset provenance

- `logo.png` and `favicon.png`: pre-existing Moch brand assets from the repository initial commit `322d80c02940b0bf8680055c2ae228145acd0789` (2026-10-05), MIT. Machine-readable origin records live beside each PNG as `<file>.json`.
- `moch/*.svg`: pre-existing Mochi artwork from the same commit, MIT. See `moch/PROVENANCE.md`.
- `og-image.svg`: hand-authored on 2026-11-26 from the Mocheme tokens and approved copy. It embeds the real favicon and a rasterized derivative of `mochi-greeting.svg` so social rasterizers render the complete mascot without cropping. See `og-image.svg.json`.
- `og-image.png`: 1200×630 raster output authored through `og-image.svg` and converted with ImageMagick 7.1.2-34. The exact prompt and intended use are embedded in the PNG and recorded in `og-image.png.json`.

No local font files, stock imagery, third-party scripts, analytics or tracking assets are used.
