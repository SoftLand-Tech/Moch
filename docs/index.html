Runs inside Moch Linux. A focused coding agent with Chat, Projects, Terminal and Browser.

  • Ubuntu guest required

  • Hermes-only surfaces are hidden

Local-first, honestly

Local-first boundary

Local-first means the agent and your workspace live on the phone. Hosted models, OpenCode’s free hosted models, downloads, OTA updates, web browsing and optional services can still use the internet. Connect a local model for on-device inference.

Current beta 1.0.53-beta.3 · build 58. Stable v1.0.0 is the legacy linked/relay build and does not include the embedded runtime or OpenCode.

On the phone

  • Moch control plane and loopback gateway
  • Sessions, projects and workspace files
  • Embedded Hermes or OpenCode in Ubuntu

May use the internet

  • Hosted model inference, including free models
  • Linux, OpenCode and package downloads
  • OTA, browsing, search and remote tools

FAQ

Common questions

Answers about the Android beta, Ubuntu guest, thinkers, and what stays on your phone. For step-by-step instructions, read the setup guide.

Which phones can run Moch?

The current local-first experience is an Android beta APK. There is no iOS release, and Expo Go is not equivalent to the current build.

Do I need to install Linux?

No, not for Hermes. Ubuntu is the default selection but can be skipped. OpenCode, the terminal and Linux tools need the guest.

Is everything offline?

No. The control plane and workspace are on the phone, but hosted models, downloads, OTA and browsing can use the internet. A local endpoint is the on-device option.

What is a thinker?

The brain that answers: Hermes or OpenCode. Hermes is the default with the broader feature set. Existing chats keep their original thinker.

Which build should I download?

Use the current beta for the local-first runtime and OpenCode. Stable v1.0.0 is the older linked/relay-only build.
