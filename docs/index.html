One phone. A real workspace.

Move from a question to a project without moving your agent to a remote machine. Tool details vary a little by thinker.

Chat

Streaming replies, visible thinking and tool activity, approvals, projects and session history. OpenCode’s reduced one-shot fallback has no token streaming or interactive permission cards.

Projects

Keep conversations and working files together. Hermes projects and OpenCode sessions stay on the phone with the workspace.

Terminal

Use terminal tabs and project working directories inside Moch Linux. Commands can install packages or reach the internet, so the terminal is a tool you direct.

Browser

Let the agent work in a visible browser tab, ask about the page, or take over when you are needed. Browsing and web search use the internet.

Local-first, honestly.

The phone owns the workspace. That is different from promising that every request stays offline.

Local-first means the agent and your workspace live on the phone. Hosted models, OpenCode’s free hosted models, downloads, OTA updates, web browsing and optional services can still use the internet. Connect a local model for on-device inference.

On the phone

  • The Moch control plane and loopback gateway.
  • Sessions and workspace files.
  • Embedded Hermes, or OpenCode inside the Ubuntu guest.

May use the internet

  • Hosted model inference, including free hosted models.
  • Linux, OpenCode and package downloads; model catalogs.
  • OTA, push registration, browsing, search, remote MCP and terminal commands.

A few useful answers.

If you are switching from the older linked setup, start with the beta guide rather than a QR code.

Which phones can run Moch?

The current local-first experience is an Android beta APK. There is no iOS release. Expo Go is not equivalent to the current CI beta APK because the native embedded-runtime bridge is unavailable there.

Do I need to install Linux?

No, not for Hermes. Ubuntu 24.04 is the default guest selection, but you can skip it. OpenCode, the terminal and Linux tools need the guest; installing it downloads files and uses the internet.

Is everything offline?

No. The agent control plane and workspace are on the phone, but hosted models, free hosted models, downloads, OTA, browsing and optional services can use the internet. Connect a local model endpoint for on-device inference. Moch does not bundle local model weights.

What is a thinker?

The thinker is the brain that answers: Hermes or OpenCode. Hermes is the default and has the broader feature set. OpenCode is an optional coding-agent thinker inside Moch Linux. Existing chats keep their original thinker.

Is OpenCode bundled, default or official?

No. Moch integrates OpenCode as an optional thinker. On first selection, Moch downloads it from opencode.ai into the Linux guest. It is not bundled in the APK, not the default, and Moch is not the official OpenCode app.

Are OpenCode’s free models on-device?

No. OpenCode’s free hosted models need no key or account, but they still use the network. Other hosted providers may require an account and charge for usage. A local endpoint is the option for on-device inference.

Which build should I download?

Use the current beta, 1.0.53-beta.3 (build 58), for the local-first runtime and OpenCode. Stable v1.0.0 is the older linked/relay-only build and should not be treated as the current local-first release.

I already used moch-link or a relay QR code. What now?

That flow belongs to stable v1.0.0. The current beta uses the on-phone setup instead. The legacy instructions are isolated at the end of the setup guide for existing users only.
